A single line of text: the message a smart fridge sends its owner at 3am.

> 3am. The ice maker and I have been talking. We think you should go to bed. The leftovers will still be disappointing tomorrow.

`main.ts` is a self-contained Node 22 program (stdlib only, no network, no
clock, no randomness) that writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
